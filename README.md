# Beauty & Wellness - Problem Definition | Week 1

**Intern: Asad | YuvaIntern | Data Science with Python Analyst**

### Selected Problem
Predicting Customer Purchase Trends, Product Recommendation Issues, and Brand Sentiment Analysis for Beauty & Wellness E-commerce (Nykaa, Mamaearth).

### Problem Statement
High cart abandonment (75%) and low personalization due to inability to predict trends and analyze brand sentiment from reviews.

### Variables & Data
Age, Gender, Skin Type, Product Price, Rating, Review Text. Data: Kaggle Sephora 1.2M Reviews, Cosmetics Dataset, Google Trends.

### Tools Proposed
Pandas, NumPy, Matplotlib, Seaborn, NLTK/VADER, Scikit-learn (Random Forest, K-Means), Collaborative Filtering.

### Industry Support
McKinsey Beauty Report 2024, Nykaa Annual Report FY23-24, Statista India Beauty Market $25.95B.

Full report DOC file is uploaded in this repo.
